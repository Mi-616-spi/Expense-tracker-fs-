# Expense Tracker App

This is a simple web app that helps you keep track of your money You can easily add what you earn and what you spend see your current balance at a glance and view a list of all your past transactions It also lets you update or remove any entry whenever you need making it easy to stay on top of your finances

Frontend (Client):-

- React : For building the user interface
- React Router : For seamless navigation between pages without reloading
- CSSv: Custom styling for a clean, modern design

Backend (Server):-

- Node.js & Express.js : For running the server and creating the REST API endpoints
- MongoDB : A NoSQL database used to safely store all your transactions
- Mongoose : For modeling and interacting with the MongoDB database

How to Run Locally:-

You will need two terminal windows to run both the server and the client simultaneously

1. Start the Backend Server
Open a terminal navigate to the `server` folder, and start the API

cd server
npm install (Only once in the beginning)
npm start


2. Start the Frontend Client
Open a second terminal navigate to the `client` folder and start the React app

cd client
npm install (Only once in the beginning)
npm start
